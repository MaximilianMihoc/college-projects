# Project Euler Solutions

Python and Jupyter solutions for the first twelve [Project Euler](https://projecteuler.net/) mathematical programming problems.

## Problems covered

- Problems 1–5: multiples of 3 and 5, even Fibonacci numbers, largest prime factor, largest palindrome product, and smallest multiple.
- Problem 6: difference between the square of a sum and the sum of squares.
- Problem 7: finding the 10,001st prime.
- Problems 8–12: largest product in a series, special Pythagorean triplet, summation of primes, largest grid product, and highly divisible triangular numbers.

The early solutions are plain `.py` scripts. Later work moves into Jupyter notebooks, with exported HTML copies for problems 8 and 9.

## What I practised

- Turning mathematical definitions into algorithms.
- Prime testing, factorisation, sequence generation, brute-force search, and grid traversal.
- Measuring where straightforward brute-force approaches become slow and motivate better algorithms.
- Using notebooks to combine explanation, code, and results.

## Running the solutions

Use Python 3 for the `.py` files. Open the `.ipynb` files in Jupyter Notebook, JupyterLab, or a compatible notebook viewer. The notebooks are self-contained and do not appear to require third-party Python packages.

## Historical note

These are learning solutions, not optimised reference implementations. For example, the early prime checks deliberately use simple trial division and some searches take noticeably longer than necessary.
