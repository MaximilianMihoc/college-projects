# Algorithms Coursework

A collection of first- and second-year exercises exploring algorithms, data structures, recursion, and functional programming in C, C#, and Haskell.

## What is here

- `C#Alg/` contains the main algorithms assignment. It implements array and generic stacks, a queue, a sorted linked list, heaps, adjacency-matrix and adjacency-list graphs, iterative breadth-first and depth-first search, and Prim and Kruskal minimum-spanning-tree algorithms. `AssignmentDocument.docx` contains the original brief about merging and searching student records across three institutes.
- `Sort/` contains a C prototype for reading and sorting student records, plus the original pseudocode and design notes.
- `SomeLabs/` contains introductory C exercises: Fibonacci numbers, leap-year checks, divisibility, a tree problem, and the recursive Tower of Hanoi.
- `Haskell/` contains early functional-programming exercises covering recursion, tuples, greatest common divisors, powers, factorials, Fibonacci numbers, tax calculations, and min/max operations.

## What I practised

- Choosing data structures to suit search and sorting problems.
- Implementing graph traversal and minimum-spanning-tree algorithms rather than relying on library versions.
- Comparing imperative and functional approaches to small problems.
- Translating written algorithms and pseudocode into working prototypes.

## Running the examples

The repository is a historical source archive rather than one buildable application. Compile individual C files with a C compiler, C# files with a compatible .NET compiler, and Haskell files with GHC/GHCi. Some examples predate modern project formats and may require small compatibility changes.
